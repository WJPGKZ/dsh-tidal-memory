# 潮汐记忆 · dsh-tidal-memory

**让同一工作区的会话记住有用的事，并在需要时带着时间和出处回忆。**

潮汐记忆是 DeepSeek Harness `0.2.1-rc.5` 的本地优先记忆插件。它把短期线索、正在进行的任务、经历和长期知识分层保存；普通记忆可检索、修改和追溯，私人日记独立保存且不在管理页显示正文。当前版本为 **0.7.0**。

> **一个虚构例子：**在工作区的一次会话中说“记住：这个项目使用 pnpm”，之后在绑定同一空间的另一会话里询问包管理方式，插件可以从仍有效的记录中找回这一线索，并附上来源。实际结果受工作区绑定、记录状态、检索门槛和预算影响；并非每句对话都会被自动记住，也不保证每次都能召回。

## 能解决什么问题

- **跨会话延续上下文**：同一工作区共享记忆，不同工作区隔离。默认保存规则能识别的用户陈述和任务，不要求逐条审核；无法可靠理解的表达可能遗漏。
- **从长期记忆找到关联**：设置页提供可缩放、拖动的关系图和可筛选的分类列表。以 L3 为中心查看来源、主题、标签和人工关联，孤立记录不会被强行连线。
- **用线索回忆，而不是把相似当事实**：标准组合使用词面、别名、时间和来源检索；可选本地 embedding 支持语义改写。图谱“可能相关”只是导航建议，不会自动合并事实或参与召回。
- **淡忘但不擅自抹除**：记录有时间、状态和生命周期；默认不会因低激活而删除。可人工修正、归档或明确遗忘，遗忘会清理当前库中的相关派生数据。
- **私人内容与普通记忆分开**：私人日记不进入普通搜索、图谱、诊断和明文备份；只有用户允许的作者插件可以写入，管理页不提供正文查看。

## 快速开始

1. 升级前停止插件写入，备份整个数据根目录。不要仅复制正在使用的单个 SQLite 文件；首次安装可跳过此步。
2. 从 [GitHub Releases](https://github.com/WJPGKZ/dsh-tidal-memory/releases) 下载一个 `standard`、`cpu` 或 `enhanced` 安装包，在 rc5 桌面端通过插件安装流程安装并启用。三者使用同一插件 ID，**不要同时安装三份**。
3. 打开 DSH 设置中的“潮汐记忆”，将工作区的**绝对路径**绑定到一个空间。空间名使用小写字母、数字、短横线或下划线；中文路径可以使用。一个空间只能绑定一个工作区，子目录不会自动继承绑定。
4. 在“分层记忆”中添加一条合成测试记录，或在已绑定工作区说“记住：……”；新建另一个会话，在“回忆与整理”中检查结果，再决定是否导入旧资料。
5. 需要语义检索时，在“设置与迁移 → 模型文件与下载”复制并手动运行对应安装命令，保存组合选择，再点击“准备本地语义索引”。标准组合不需要模型。

升级后，已运行的 DSH 需由用户重载插件或重启宿主，页面才会显示新版本。GitHub Release 安装包不等于已发布到 npm，也不代表已经在每个桌面环境中完成验收。

### 选择安装组合

| 组合 | 默认能力 | 本地模型 |
| --- | --- | --- |
| `standard` | 词面、别名、时间和来源检索；完整四层与图谱 | 不加载模型 |
| `cpu` | 上述能力加本地语义检索 | BGE-small-zh-v1.5，512 维，CPU；权重约 90.5 MiB |
| `enhanced` | 上述能力加本地语义检索 | Qwen3-Embedding-0.6B，1024 维；权重约 1.12 GiB，提供 Windows x64 Vulkan/CPU 引擎 |

三个包共用记忆结构，区别仅在初始语义组合；已经保存的设置优先于包默认值，也可以在设置页切换。模型和运行时不包含在插件包中，模型下载需要联网，但**记忆 embedding 在本机完成**。增强版指模型规模，不保证每个问题都优于 CPU 版。

设置页显示实际模型目录和带绝对路径的安装命令。也可在插件目录手动运行，先把占位内容替换为设置页显示的数据根：

```powershell
node scripts\setup-model.mjs --edition cpu --root '<数据根绝对路径>'
node scripts\setup-model.mjs --edition enhanced --root '<数据根绝对路径>'
```

安装脚本固定模型版本并校验权重与引擎 SHA-256；已安装包在加载时再次校验。下载来源为 [BGE ONNX 固定版本](https://huggingface.co/Xenova/bge-small-zh-v1.5/tree/75c43b069aac4d136ba6bc1122f995fedcfd2781) 和 [Qwen 官方 GGUF 固定版本](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B-GGUF/tree/370f27d7550e0def9b39c1f16d3fbaa13aa67728)。缺少模型或加载失败时会明确提示并降级到词面检索，不影响普通记忆保存。

## 设计：像回忆一样分层，但不冒充大脑

| 层 | 保存什么 | 默认处理 |
| --- | --- | --- |
| **L0 感知缓冲** | 短期用户会话线索 | 已处理的缓冲默认保留 72 小时；助手全文默认不捕获 |
| **L1 工作记忆** | 当前任务和待办 | 规则生成的任务默认 24 小时到期归档，可调整 |
| **L2 情景记忆** | 带时间和来源的经历、陈述 | 按线索召回；足够独立的重复证据可经本地规则提炼 |
| **L3 长期知识** | 稳定偏好、约定和知识 | 默认作为有效长期背景常驻，仍受状态、有效期和预算限制 |

灵感来自分层记忆、遗忘和线索回忆，具体实现是可解释的本地规则和检索，并非真实神经网络模拟。每条普通记录区分用户陈述、观察、推断等性质，保留时间、版本和来源。**自动保存、常驻、相似度或人工关联都不等于事实已核实。**

日常整理使用本地规则；明确冲突、保护项和来源约束不会被相似度直接覆盖。规则抽取有边界，尤其可能漏掉隐含信息或任务表达；本地 embedding 只用于检索和导航，不生成结论。当前 rc5 未提供经验证且同时满足后台审计与隔离的整理接口，**普通自选生成模型、手填 API 和普通 L0 模型提取均暂不可用**，插件不会绕过宿主审计自行发送整理请求。

### 图谱如何使用

打开“记忆图谱”，默认查看当前有效的 L3。可以按层级、状态、主题或标签、关系类型和文字筛选；点击节点查看关联依据、正文和出处，再选择确认、排除或撤销关联。主题与标签支持编辑；没有足够分类线索的记录显示为“待归类”。图谱是已有记忆的视图，不是第五层或另一套事实主库。

已准备本地语义索引时，可点击节点的“查找可能相关”。建议仅供导航，按批有界扫描，每批最多显示 10 个候选；相似文本可能有不同主体、否定、数值或有效时间，长文本分块取最高相似度也可能误报。人工确认只表示两条记录有关，不表示内容相同。

**图谱辅助召回默认关闭。**手动开启后，仅从通过词面证据门槛的已选记录出发，在剩余预算内追加最多 3 条有效的人工确认关联；与既有来源关联共最多 5 条，不挤掉原本选中的证据。纯语义命中、共享主题和未经确认的语义建议不会自动扩散。人工排除的来源关联不再沿该边扩散。

人工关联也可能与本次问题无关或包含冲突信息，建议先在“回忆与整理”中模拟检查。在隔离合成预留集的 40 个图谱适用场景中，目标证据从 0/40 提高到 40/40，但该组难负例没有人工关联边。额外加入有确认关联的跨主体、跨时间难负例后，20/20 条被错误追加，新增项相关率为 40/60；标准、CPU、增强组合及两种常驻设置结果一致。因此不能据此默认开启，也不能将合成结果当作真实使用准确率。10,000 条规模下默认 L3 常驻的召回 P95 初测超过门槛；单独复测波动明显，随后三次均未达到门槛，不作为延迟保证。

## 设置与默认值

设置页内提供总览、分层记忆、记忆图谱、回忆与整理、私人日记，以及设置与迁移。大部分选项可直接修改：

| 项目 | 默认值 |
| --- | --- |
| 自动捕获用户陈述、普通记忆上下文注入 | 开启；仅规则识别到的内容进入长期层级 |
| L3 常驻 / 预算 | 全部当前有效 L3；独立额度 16,000 字节，计入总预算 |
| 普通检索 / 总预算 | 最多 30 条 / 48,000 UTF-8 字节估算，不是精确 token 数 |
| 本地深整理 / 日期 | 本地规则；每天本机时间 03:00，空闲后执行 |
| 图谱辅助召回 / 自动归档 | 关闭 / 关闭 |
| 备份 | 自动备份开启，默认**明文**普通记忆；每种保留 14 个恢复点 |
| 私人作者 | 空白名单，默认没有作者可以写入 |

关闭“上下文注入”只停止自动注入，模型主动调用普通记忆工具仍可读取；如果不希望捕获、注入和使用记忆工具，应关闭插件的 `enabled`。L3 常驻不代表内容已经核实，过时记录应及时编辑或归档。

## 文件位置

默认根目录为 `<DSH_HOME>\tidal-memory`；设置页显示本机的实际代码、模型、索引和备份位置。`dataRoot` 可以在配置中指定其他绝对路径，切换前需停止插件并完整迁移数据。

```text
<数据根>\
  models\                              本地模型与运行时，多个空间共用
  spaces\<空间名>\
    L0-buffer\buffer.sqlite3           短期普通缓冲
    L1-working\working.sqlite3         工作记忆
    L2-episodes\episodes.sqlite3       情景记忆
    L3-long-term\long-term.sqlite3     长期知识
    private\journal.sqlite3            私人日记独立库
    system\operations.sqlite3          运行状态和人工图谱修正
    indexes\topics.sqlite3             可重建的普通主题索引
    indexes\semantic.sqlite3           可重建的普通向量索引
    indexes\graph.sqlite3              可重建的普通图谱索引
  backups\<空间名>\                    自动和手动恢复点
  secrets\automatic-backup.dpapi        Windows 自动备份口令
  system\forget-ledger.sqlite3         同谱系遗忘标记，不含正文
```

L1–L3 的可读 `views` 也是派生文件；请在设置页修改主记录，不要通过编辑视图替代修改。图谱索引不保存第二份正文，向量和索引仍属于敏感派生数据。一个空间同时只允许一个写入者，其他写入进程会收到 `SPACE_BUSY`，不会抢锁或把空库伪装成成功。

## 隐私、备份与恢复

- **本地不等于与模型隔离**：规则、索引和 embedding 在本地运行；启用自动注入或调用记忆工具时，选中的普通记忆会随 DSH 的正常聊天请求发送给你配置的聊天模型。宿主会话日志及服务提供方的保留策略不由本插件控制。
- **私人日记不是安全沙箱**：每个获准作者在同一空间的本地日历日内只维护一份正文，轻整理直接修改这份正文，不产生第二份整理稿。界面和普通工具不读取其内容；但私人 SQLite 本机未静态加密，同账户文件工具或同进程代码仍可能访问，必要时请配合磁盘加密和文件权限。
- **明文备份含敏感普通正文**：默认备份包含普通 L1–L3、修订、遗忘标记和人工图谱修正，不含 L0、私人日记、模型、派生索引或来源摘录。校验和只能发现损坏，不提供保密。深整理前即使关闭自动备份也会先创建恢复点。
- **可选加密**：设置页可选择加密普通记忆，或加密普通记忆与私人日记；使用 scrypt 与 AES-256-GCM。Windows 自动备份口令由当前账户 DPAPI 保护，保护失败不会回退明文。请离线保存原口令并演练恢复；忘记口令无法解密，换口令也不会更改旧备份。切换加密不会删除已有明文副本。
- **恢复与回退**：备份恢复到不存在的新空间，不覆盖当前空间。0.7.0 可读取旧版备份；新备份使用版本 2，旧版会拒绝而非静默丢弃图谱修正。需要回退时，停止插件并使用升级前完整数据根副本及对应旧版。
- **遗忘有边界**：当前库和同数据根的同谱系恢复会协调已知遗忘标记，但无法远程改写旧离线备份、原文件、DSH 会话历史或外部服务记录；它也不是磁盘法证级擦除。旧备份可能含早期 L0 内容，请自行检查。

旧文件仅在用户选择并预览后导入，不自动扫描或批量迁移。私人资料应单独选择私人导入；文件名识别不能保证识别所有私人内容，混合文件应先拆分。

## 进阶接口与验证

普通工具包括 `tidal_remember`、`tidal_recall`、`tidal_timeline`、`tidal_read_evidence` 和 `tidal_correct`。出处可按 ID 或主题分页读取；历史、归档和指定时点需显式选择。删除和私人清空只在管理页确认，不提供给模型自动执行。其他插件可通过宿主 `tidalMemory` 服务使用普通记忆或申请仅写入的私人作者能力，类型见 `index.d.ts`。

开发需要 Node.js 24 和 pnpm；测试与预览使用隔离合成数据，不读取用户记忆：

```powershell
pnpm install:host
pnpm check
pnpm test:unit
pnpm test:host
pnpm test:ui
pnpm bench:graph
```

本地模型准备完成后，可设置 `TIDAL_MODEL_ROOT` 并运行 `pnpm test:models`、`node scripts\evaluate-graph-semantic.mjs` 和 `node scripts\evaluate-graph-recall.mjs`。设置 `TIDAL_GRAPH_SPLIT=challenge` 可复现上述未通过的关联难负例；脚本会以失败退出码报告未达门槛。自动化宿主和浏览器检查不等同于真实桌面端的完整使用验收。历史变更见 [Releases](https://github.com/WJPGKZ/dsh-tidal-memory/releases)。
